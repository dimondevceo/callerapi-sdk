# Contributing

This repository is a generated distribution mirror for the CallerAPI iOS SDK.
Its contents are published automatically from CallerAPI's internal monorepo on
every release, so pull requests against it cannot be merged — any change made
here is overwritten by the next release.

To report a bug or request a change, open an issue:
https://github.com/dimondevceo/callerapi-sdk/issues

For commercial and licensing questions: support@callerapi.com
